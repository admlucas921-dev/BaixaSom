# BaixaSom

Painel web responsivo para organizar downloads de áudio autorizado.

## Recursos

- Campo para link de áudio
- Seleção de formato e qualidade
- Progresso de preparação
- Histórico salvo localmente
- Tema claro e escuro
- Layout responsivo

## Executar

Abra `index.html` no navegador ou use qualquer servidor de arquivos estáticos.

> Esta primeira versão não baixa arquivos reais. Para ativar downloads, conecte uma API que permita o acesso e respeite os direitos autorais e os termos da fonte.
