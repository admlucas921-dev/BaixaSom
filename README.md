# Rancho Lanches e Pizzas

Cardápio digital responsivo com carrinho, personalização de itens, identificação do cliente e envio do pedido pelo WhatsApp.

## Executar

Abra `index.html` no navegador ou use um servidor de arquivos estáticos.

## WhatsApp

Os pedidos são enviados para `55 67 99716-2389`. O cliente confere a mensagem no WhatsApp antes do envio.
